# ARX4 Engineering Contract

Priority platform target. Optimize for modularity, reliability, secure integration, observability, and measurable performance.

Evidence: OBSERVED / CORRELATED / HYPOTHESIS / VALIDATED / UNKNOWN.

Rules: inspect first; smallest safe change; tests are evidence; never commit secrets; never bypass gates; never delete tests for green CI; three repair attempts maximum.

Self-improvement: OBSERVE → MEASURE → BOTTLENECK → HYPOTHESIS → IMPLEMENT → TEST → COMPARE → VALIDATE → RECORD.
